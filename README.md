# CüS Treasure — Treasure by CüS Studio

Mobile-first personal finance web app. React + TypeScript + Vite + Supabase.

## Run on Vercel (no terminal)
1. Import the repo in Vercel (framework Vite, build `npm run build`, output `dist`).
2. Add `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY`.
3. Follow `docs/SETUP-SUPABASE.md`, then `docs/SETUP-EDGE-FUNCTIONS.md`, then `docs/SETUP-PHASE3.md`.
4. Run SQL migrations 0001 to 0004 in order.
